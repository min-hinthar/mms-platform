## How the round ran

Seven read-only mappers walked the paths as built (dine-in, to-go, grocery, counter, kitchen and expo, arrival/account/after, manager and the staff shell) and one extracted the visual system; a lead designer picked eight moments the first round had not designed, excluding m1–m12 and the sixty decided IDs unless the as-built code showed friction the record had not foreseen. Three concept agents per moment (Quiet · Guided · Glanceable, two screens each) and a three-seat judge panel per moment followed; the 48 concept artboards were drawn from their briefs. The owner was asked once. One agent per moment then synthesized a refined spec from the judges' pick, the grafts and the recorded defaults, checking every product claim against `09c1c2a`; ONE consistency agent read all eight specs and set the shared vocabulary below; an adversarial critic reviewed each amended spec; the refined screens were drawn with the critic's blocking fixes applied. Each spec ends in appendices (A) the consistency amendments, (B) the critic's blocking fixes, (C) its suggestions — **where an appendix contradicts the spec body, the appendix wins**, and where two specs' appendices disagree, _Cross-spec reconciliations_ below wins over both. The infrastructure facts of the run (four CPU cores cap a workflow at two concurrent agents; two container restarts; one usage-limit pause) are in the PR, not here.

**Burmese:** every new Burmese string in the specs is a draft for the native sitting (K15), never final copy. Reused shipped strings are cited to their file and line. Strings with no draft stay English-only and are listed in each spec.
